These tests prove bounded synthetic body/request behavior only. Arbitrary Go JSON/URL grammar, physical network cancellation, default client TLS/proxy/network behavior, native platforms, and dropping an Ordered future during async Body.Close remain separate unverified obligations. No public source probes, uploads, accounts, or external services are used.
