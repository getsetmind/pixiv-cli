## Production ports

`diagnostics::Presenter` implements the SDK Sink with a normal writer and clock. `command_diagnostics::CommandDiagnostics` owns a presenter/scope for a root invocation. The concrete SDK context mapping shares cancellation/deadline/value state; the generic caller-context adapter delegates all parent ports and replaces only the diagnostic scope. Diagnostics retain the first writer error and keep attempting later records. Main must invoke finish exactly once after command resource cleanup.

The final event is selected from the business/cleanup result before reading the retained diagnostic error. A diagnostic-only writer failure therefore still emits completed and then makes the command fail. Go joins causes; NDJSON suppression examines wrapped/joined EPIPE before usage, and can suppress a simultaneous business or usage failure. These surprising behaviors are preserved.
